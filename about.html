What is Kirby Air Riders Garage?

カービィ エアライダー ガレージ とは？

|

Kirby Air Riders Garage is a central hub for Kirby Air Riders Speedrunning run by @noodl999. It consolidates records from Speedrun.com and Speedrider to display them all in one convenient location.

How does it work?

Using Google Sheets Apps Script, it pulls data from Speedrun.com’s API and scrapes Speedrider’s HTML tables, then transposes the data into readable tables that you can sort by column. This is done automatically every 6 hours, starting at 12am EST. Please note that while the data is refreshing, some tables may appear empty.

仕組み

Google スプレッドシート と Apps Script を用いて Speedrun.com の API からデータを取得し、Speedrider の HTML テーブルをスクレイピングします。 取得したデータを整形し、列ごとの並べ替えが可能な読みやすい表に変換しています。この処理は、米国東部時間（EST）で毎日午前0時を起点に、6時間ごとに自動実行されます。データ更新中は、一時的に一部の表が空に表示される場合がありますのでご了承ください。
