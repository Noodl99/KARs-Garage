What is Kirby Air Riders Garage?

Kirby Air Riders Garage is a central hub for Kirby Air Riders Speedrunning run by @noodl999.

It consolidates records from Speedrun.com and Speedrider to display them all in one convenient location.

How does it work?

Using Google Sheets Apps Script, it pulls data from Speedrun.com’s API and scrapes Speedrider’s HTML tables, then transposes the data into readable tables that you can sort by column.

Kirby Air Riders Garage とは？

Kirby Air Riders Garage は、 @noodl999 が運営する、Kirby Air Riders のスピードラン記録を集約するハブサイトです。

記録は Speedrun.com と Speedrider から収集し、1 つの場所に見やすくまとめて表示します。

仕組み

Google Sheets の Apps Script を使用し、Speedrun.com の API からデータを取得、さらに Speedrider の HTML テーブルをスクレイピングします。取得したデータを整形して、列ごとの並べ替えができる読みやすい表に変換しています。
